# Читанка — онлайн-бібліотека (MVP)

Лабораторна робота № 6 з дисципліни «Мови програмування для web»:
мінімальна видима версія продукту на Ruby on Rails за специфікацією вимог (SRS) з лабораторної роботи № 2.

Автор: Мельник В.Я., група ІП-23-2.

## Можливості

- каталог книг із пошуком за назвою, автором або ISBN (кирилиця без урахування регістру), фільтрами за жанром, роком і наявністю, сортуванням і пагінацією;
- головна сторінка за макетом SRS: оголошення, «Нові надходження», «Популярне цього місяця»;
- реєстрація читача, вхід і вихід (генератор `rails generate authentication`);
- бронювання вільного примірника на 3 дні, «Мої бронювання», скасування;
- відгуки з оцінкою 1–5 і середня оцінка книги, особисті полиці;
- розділ бібліотекаря: книги, автори, жанри (CRUD), видача та повернення книг;
- розділ адміністратора: ролі та блокування користувачів.

## Технології

Ruby 3.4.9, Rails 8.1.4, SQLite 3, Puma, Propshaft, Hotwire (Turbo); ОС розробки — Ubuntu 24.04 у VirtualBox.

## Запуск

```bash
bundle install
bin/rails db:prepare   # створює БД, виконує міграції та заповнює тестовими даними (db/seeds.rb)
bin/rails server       # http://localhost:3000
```

## Що згенеровано, а що написано власноруч

У кожному файлі на початку є коментар `[згенеровано]` (яка команда Rails створила файл) і `[власний код]` (що дописано вручну); у змішаних файлах власні блоки позначено `# ---- власний код ----`.

| Команда / джерело | Що створила |
|---|---|
| `rails new chytanka` | каркас застосунку, конфігурація, `ApplicationController`, макет |
| `rails generate authentication` | `User`, `Session`, `Current`, `SessionsController`, `PasswordsController`, concern `Authentication` |
| `rails generate scaffold Genre / Author / Book` | моделі, міграції, CRUD-контролери, шаблони, маршрути `resources` |
| `rails g model BookAuthor / Reservation / Review / ShelfItem` | моделі та міграції зв'язків |
| `rails g migration AddNameAndRoleToUsers` | міграція полів `name`, `role` |
| `rails g controller Home index` | `HomeController`, шаблон головної сторінки |
| власний код | зв'язки й валідації моделей, пошук і фільтри, бронювання, відгуки, полиці, розділи бібліотекаря й адміністратора, `RegistrationsController`, усі шаблони інтерфейсу, CSS, локалізація `uk.yml`, `db/seeds.rb` |
